# Episode diversity

Episode diagnostics group nearby candidate windows by instrument, timeframe, and configurable bar-distance bucket. For each neighbour set the engine reports:

- raw neighbour count;
- unique episode count;
- largest episode share;
- top-three episode share;
- instrument concentration;
- episode-adjusted effective sample size;
- diversity flags.

The retrieval utility can enforce a maximum number of matches per episode for bounded diagnostics.
