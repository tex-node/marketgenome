# Study manifests

Study manifests live under `research/studies/` and are JSON-compatible `.yaml` files. The initial manifest is:

```text
research/studies/multi_asset_episode_study_v1.yaml
```

The manifest predefines universe, data requirements, windows, horizons, retrieval constraints, methods, baselines, gates, and random seed. Missing instruments are reported by dataset entries rather than silently inferred.
