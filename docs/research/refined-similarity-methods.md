# Refined similarity methods

Step 10A adds transparent refined methods:

- `dna_robust_cosine_v1`;
- `dna_robust_euclidean_v1`;
- `dna_group_balanced_v1`;
- `shape_dna_context_v2`.

These methods are still deterministic distance functions. They add robust compression, availability coverage diagnostics, group-balanced contribution, and explicit context decomposition. They do not use future outcomes.
