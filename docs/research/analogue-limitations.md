# Analogue Limitations

Phase 1 analogue retrieval is intentionally simple.

Limitations:

- no ANN/vector index yet;
- no learned embeddings;
- no purged walk-forward experiment runner;
- context compatibility is a simple dimension-match distance;
- missing Market DNA features reduce common-feature coverage;
- similarity quality is not yet validated against forward outcomes.

Forward outcomes should be joined after retrieval for evaluation, not during similarity scoring.
