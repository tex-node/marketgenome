# Swing structure method

The first swing method is `local_extrema_v1`.

It identifies extrema using local three-point comparisons on the normalized close path, includes the first and last points, and derives swing sizes and durations between adjacent extrema.

Implemented structure features include swing count, average/median/max swing size, average swing duration, impulse-to-pullback ratio, and higher-high/lower-low style counts.
