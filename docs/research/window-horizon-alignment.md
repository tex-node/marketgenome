# Window/horizon alignment

Window/horizon diagnostics report ratios between source-pattern length and outcome horizon. The initial matrix supports:

- window lengths: 8, 16, 32, 64, 128, 256;
- horizons: 1, 3, 5, 10, 20, 40, 60, 80;
- ratio buckets around 0.125, 0.25, 0.5, 1.0, and 2.0.

The purpose is to detect scale/horizon mismatch, not to tune on a final test period.
