# Persistence and complexity features

`market_dna_v1` includes early descriptive persistence and complexity measures:

- `hurst_rs_v1`
- `variance_ratio_2`
- `variance_ratio_4`
- `permutation_entropy`
- `sample_entropy`
- `higuchi_fractal_dimension`
- `turning_point_count`
- `turning_point_density`

These are descriptive research features, not predictive claims.
