# Similarity Search Operations

CLI examples:

```powershell
market-genome similarity methods
market-genome similarity method-show market_analogue_v1
market-genome similarity search <window_id> --top-k 20
market-genome similarity queries
market-genome similarity query-show <query_id>
market-genome similarity matches <query_id>
```

Run similarity after windows, normalization, features, and context have been built for the target dataset.
